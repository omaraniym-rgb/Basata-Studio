# content

`weeks/YYYY-MM-wN.json` hold one week of post specs: slot (Mogadishu time), type, format, image text, captions per platform, platforms, status and the expected files on Drive.

Rules for what goes in a post live in ../CLAUDE.md. The calendar of record is still Notion (Basata · Content · October 2026); these files are an export so Claude can read, check and draft against them. Media stays on Drive › Basata 2.0 › Content.

W3–W5 are placeholders in Notion for now (one row each, no posts yet).
